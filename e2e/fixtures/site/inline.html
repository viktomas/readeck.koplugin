Notes on Inline Markup

Plain paragraphs are the easy case, because every character sits in a single text node that starts at the paragraph.

This paragraph has an emphasised phrase in the middle, and the words after it live in a second text node of the same paragraph.

Here a bold run and a link to elsewhere both appear before the sentence finally comes to an end.
